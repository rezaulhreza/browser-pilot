Hermes in Chrome

Your agent works in one tab, kept in its own tab group. It cannot see or change any other tab.

Checking the connection

Connection

The bridge is the small program on this computer that your agent talks to. It listens on 127.0.0.1 and this port. Change it only if you started the bridge on a different port.

The agent's tab

Used for the tab group, the border around the page and the agent's pointer.

Sites the agent may never open

A name also covers everything under it, so example.com blocks accounts.example.com too. If a link leads the agent to a blocked site, its tab is cleared straight away.
