Browser Pilot

Your agent works in its own tab group. It can open several tabs there, but it cannot see or change any tab outside the group.

Checking the connection

Connection

The bridge is the small program on this computer that your agent talks to. It listens on 127.0.0.1 and this port. Change it only if you started the bridge on a different port. To let several agents work at the same time, start one bridge for each on its own port and list the ports here with commas between them, such as 8790, 8791. Each agent gets a tab group of its own.

The agent's tabs

Used for the tab group, the border around the page and the agent's pointer. With several bridges, the first one has this colour and each one after it takes the next colour on the list, so you can tell the agents' tabs apart.

Sites the agent may never open

A name also covers everything under it, so example.com blocks accounts.example.com too. If a link leads the agent to a blocked site, its tab is cleared straight away.
